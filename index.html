About Me

Hey, I am Sunidhi Mahajan

🎓 First Year BTech Student who made a project "PINK TRACKER". Pink Track is a simple and user-friendly web application designed to help users track their menstrual cycle easily. It allows users to enter basic cycle details like start date, cycle length, and period duration to predict the next period, ovulation day, and fertile window. The application also includes additional features like a mood tracker and personal notes section, enabling users to monitor both physical and emotional health in one place. Built using HTML, CSS, and JavaScript, the project focuses on a clean UI with a soft aesthetic design, making it both functional and visually appealing.
